### 👨‍💻 关于我

一位专注 Android 深水区的独立开发者 ——
擅长把"不可能在手机上跑的东西"变成现实：**设备端自主 AI 智能体、PRoot 沙箱 Ubuntu 终端、
仿生认知记忆系统、Root/免 Root 双形态 Xposed 模块**。相信下一代的个人 AI 伴侣
不需要云端、不需要服务器，只需要一台随身携带的 Android 设备。

🔭 当前主项目：**[Android Guru Agent](https://github.com/AceGuru-mjh/Android-Guru-Agent)** —— 24 万行 Kotlin、109 个工具、跑在手机上的自主智能体

🛠️ 也在造：LSPatch 免 Root Xposed 模块合集 · 16 层 Root 检测 · WebGL 官网

💬 问我：Kotlin/Compose、Android 逆向与 Hook、PRoot/终端模拟、LLM Agent 工程

⚡ 冷知识：一个人 + AI 协作，可以顶一个团队
